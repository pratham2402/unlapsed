# Sample documents

These are fictional, text-based PDFs for one persona, Alex Morgan. They are generated by `scripts/generate_sample_pdfs.py` with ReportLab.

Do not use real people's passports, licenses, policies, or certificates in the demo. The point is to show the workflow, not to expose anyone's identity.

The files are text PDFs, not scans. The app uses `pypdf` and does not OCR images. A scanned PDF is rejected with a clear message. This is a deliberate demo choice: it keeps the extraction path deterministic and avoids pretending that OCR is solved.

To regenerate the files:

```bash
uv run python scripts/generate_sample_pdfs.py
```
